# Excel 导入与导出

Excel 导入导出属于大批量数据处理。沿用项目已有的 Listener、模板、导出工具和权限机制，不要在 Controller 一次性读取或构造全部对象。

## 导入

- 明确并校验文件类型、文件大小、行数、列结构和业务唯一键；限制值使用项目配置或需求中可追溯的阈值。
- 使用流式读取和分批持久化，控制每批次事务范围。禁止一次性把所有行读入内存或逐行查询数据库。
- 记录可定位的错误行、列和原因，并明确遇错继续、终止或回滚的业务语义。导入重试必须遵循 [reliability.md](reliability.md) 的幂等规则。

## 导出

- 导出前执行权限和数据范围过滤，导出字段使用专用 `XxxExportVo` 或项目已有导出模型，不能直接导出 Entity。
- 大数据导出分页或分批写出，禁止一次性查询并加载全部对象；评估异步任务、文件存储或下载时效是否为项目既有模式。
- 导出内容包含用户可理解的列名和状态展示，但展示转换在 Java/导出模型中完成，不转移到 SQL。
