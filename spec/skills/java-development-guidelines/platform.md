# 配置与 Maven 依赖

环境相关参数必须通过项目既有配置体系注入，依赖变更必须最小且可解释。

## 配置管理

- 数据库/Redis 地址、第三方服务地址、超时、Token、密钥等不得硬编码在 Java 代码中；新增配置复用现有配置文件和绑定方式。
- 新增配置说明用途、默认值、环境覆盖方式和是否敏感。不得提交真实生产配置、`.env` 密钥或在日志中输出敏感配置。
- 测试配置与生产配置严格隔离，禁止把测试凭证或不安全默认值复制到生产环境。

## Maven 依赖

- 新增依赖前确认项目是否已有同类能力、Spring Boot BOM 是否已管理版本、安全风险和维护成本。
- 禁止为简单工具引入第三方库、覆盖 Spring Boot 管理版本或随意升级基础依赖。
- 修改依赖或版本时说明原因、影响范围和版本兼容性；涉及基础框架升级按高风险操作处理。
