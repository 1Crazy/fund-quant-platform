# 前端开发规范

此 skill 是 `fund-web` 的项目级规则入口。后续在此集中维护前端开发、交互、接口联调和排错经验。

## 详情交互与导航

- 业务对象的查看详情必须在其来源列表、看板或工作台内以抽屉呈现；不得新增或恢复独立的详情路由、详情页或全屏详情视图。
- 抽屉从右侧打开，桌面端使用稳定的工作台宽度，移动端占满可视宽度；关闭时必须返回原有列表筛选、分页和滚动上下文。
- 列表行、明确的“查看详情”操作和可分享的深链接都应打开同一个抽屉。需要兼容的历史详情 URL 必须重定向到来源列表，并保留对象标识以自动展开抽屉。
- 抽屉加载或切换对象时必须展示该对象的加载状态，不得短暂复用上一对象的详情数据。抽屉内的编辑、刷新和权限控制沿用原业务能力。
- 只有用户明确要求独立详情页，或详情必须作为可打印、可导出、可公开访问的独立文档时，才允许例外；例外需要在对应 OpenSpec 或需求中记录原因。
